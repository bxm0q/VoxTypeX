# Ручная проверка VoxTypeX

Проводите проверку в пустом документе Блокнота, без важных данных.
Не запускайте вторую копию VoxTypeX. Журнал: `%LOCALAPPDATA%\VoxTypeX\logs\voxtypex.log`.

1. ☐ **Запуск.** Распакуйте готовый архив и запустите `VoxTypeX.exe` двойным щелчком.
   В трее появился значок, статус Ready; постороннее окно не активировалось.
2. ☐ **Микрофон.** Откройте «Настройки…», выберите доступный микрофон и Auto для языка,
   сохраните. Повторно откройте настройки — выбор сохранился.
3. ☐ **PTT.** Нажмите «Изменить клавишу», нажмите и отпустите F8.
   Назначение сохранилось, запись при этом не началась. Закройте настройки.
4. ☐ **Notepad.** Откройте пустой документ Блокнота, щёлкните в поле текста.
5. ☐ **Удерживание.** Зажмите F8. Появился индикатор «Запись», фокус остался в Блокноте.
6. ☐ **Фраза.** Удерживая F8, произнесите: «Привет, это проверка голосового ввода».
7. ☐ **Отпускание.** Отпустите F8. Появилась обработка. При первом запуске допустимы
   отдельные статусы скачивания и загрузки модели; не закрывайте приложение.
8. ☐ **Текст.** Дождитесь текста в Блокноте и возврата Ready. Фраза вставлена один раз,
   без отправки Enter. Пока ждёте, не печатайте и не переключайте поле.
9. ☐ **10 повторов.** Повторите шаги 5–8 десять раз с той же фразой.
   Между попытками дождитесь Ready; перенос строки при необходимости делайте вручную.
   Нет пропущенных/двойных вставок, зависшего индикатора или постоянного роста нагрузки.
10. ☐ **Перезапуск.** Через трей выберите «Выход», затем снова запустите VoxTypeX.
    Микрофон и F8 сохранились. Повторите одну фразу — запись и вставка работают.

Короткие дополнительные проверки:

- ☐ «Отключить» в трее: F8 не записывает; после включения и нового нажатия работает.
- ☐ В назначении клавиши Escape отменяет изменение; во время записи отменяет эту запись.
- ☐ Во время обработки повторное PTT не запускает второй поток записи.
- ☐ Начните диктовку в одном поле и переключитесь в другое окно или другое поле
  до завершения обработки: текст не появляется в новой цели. Повторите обычную
  диктовку без переключения — вставка работает один раз.
- ☐ Выберите отдельную модель и Русский, начните скачивание, отмените, повторите.
  Прогресс возобновляется при поддержке Range; при отключённой сети показана ошибка,
  частичный файл остаётся для повторной попытки. GUI отвечает во время загрузки.
- ☐ Установите компактные модели RU/UK/EN. После каждого выбора нажмите «Сохранить»
  и продиктуйте фразу на соответствующем языке без перезапуска приложения.
  Повторная фраза использует уже загруженную модель, без повторного скачивания.
- ☐ Проверьте длинную фразу с паузами, отмену Esc во время обработки и следующую
  обычную запись: отменённая фраза не вставляется, новая обрабатывается.
- ☐ Выберите «Автоматически» с отдельным backend: используется Whisper.
  Верните явный язык и отключите доступ к его файлу модели в тестовом кэше:
  показывается fallback, вставка Whisper выполняется один раз. Верните файл.
- ☐ Выйдите через трей во время обработки: GUI и дочерний процесс завершились,
  поздний результат не вставился. Повторите на Windows 10 x64 и Windows 11 x64.

Звуковой тракт:

- ☐ Открытие настроек не запускает микрофон. «Записать тест» показывает уровень;
  оригинал и обработка одной записи прослушиваются отдельными кнопками. При
  закрытии/смене микрофона тест прекращается, запись очищается из памяти.
- ☐ Сравните шумоподавление «выкл / умеренное / сильное», тихий голос и щелчки.
  Проверьте пик и clipping. Выключите VAD и шумоподавление для полного bypass.
- ☐ С VAD произнесите короткое «да» сразу после PTT, затем фразу с тихим окончанием.
  При удержании PTT после длинной начальной/внутренней паузы речь сохраняется.
- ☐ С автостопом 3 с короткая пауза не прерывает фразу. После автостопа отпустите
  PTT и начните новую запись; Esc по-прежнему отменяет результат.
- ☐ Отключите USB-микрофон во время записи: есть ошибка, скрытой замены нет.
  Переподключите, обновите список и выберите устройство. Windows default требует
  отдельного подтверждения; смена клавиши и выключение/включение приложения его не заменяют.

При сбое запишите номер шага, время, выбранный микрофон/модель и сообщение UI.
Техническая причина должна быть в журнале, а не в большом traceback на экране.
Этот чек-лист не считается выполненным автоматически после прохождения pytest.

Предпросмотр:

- ☐ Включите предпросмотр, VAD и индикацию. Удерживая PTT, говорите 15–20 секунд
  с короткой паузой. Текст в overlay меняется, исходное поле остаётся пустым.
  Отпустите PTT: в прежнем поле появляется один окончательный текст.
- ☐ Смените поле/окно после первой гипотезы, в том числе вернитесь обратно.
  Поздний текст не появляется ни в старой, ни в новой цели. Повторите с Esc,
  открытием настроек и выходом во время preview-inference.
- ☐ Длинная начальная пауза, отдельное короткое «да», тишина и речь после паузы:
  сегмент без текста не блокирует последующую фразу; тишина не даёт вставку.
- ☐ Повторите на выбранных RU/UK/EN-моделях и Whisper, затем выключите предпросмотр:
  обычная PTT-вставка работает. Сравните интервалы 1 / 3 / 10 с и CPU-метрики.
- ☐ На Windows 10/11 проверьте Python, EXE, распакованный ZIP и установленную сборку.
  [Автоматизированный replay smoke](TRANSCRIPT_PREVIEW.md) — дополнительная проверка.
