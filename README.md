# VoxTypeX

Приложение голосового ввода для Windows: работает в трее и вставляет распознанную
речь в исходное текстовое поле другой программы.

**Hold → Speak → Release → Text**

Зажмите Push-to-Talk, произнесите фразу, отпустите клавишу и дождитесь текста.
Распознавание выполняется локально через faster-whisper / CTranslate2;
аудио не отправляется на сервер.

## Возможности MVP

- Глобальная PTT: Right Alt по умолчанию, Right Ctrl, F6–F9, F11–F24, кнопки мыши 4/5.
- Выбор микрофона, Auto / Russian / Ukrainian / English и Tiny / Base / Small.
- Индикаторы записи, скачивания, загрузки модели, обработки, вставки и ошибки без перехвата фокуса.
- Трей: «Настройки…», «Отключить / Включить», «Выход». Esc отменяет текущую операцию.
- Проверка исходного поля перед вставкой, безопасное восстановление буфера обмена,
  Unicode-вставка при недоступном безопасном буфере.
- Сохранение настроек и журнал технических ошибок с ротацией.

## Требования

- Windows 10/11 **x64**, обычный рабочий стол и микрофон с mono PCM16 / 16 кГц.
- Разрешённый доступ настольных приложений к микрофону.
- Практический ориентир: 8 ГБ RAM и 3 ГБ свободного места для программы, модели и загрузки.
  Tiny/Base подходят для менее мощного ПК.
- Интернет для первого скачивания выбранной модели; затем можно работать офлайн.
- При отсутствии runtime DLL установите
  [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).

Python и NVIDIA для готовой сборки не нужны. Основной проверяемый путь — CPU/int8.
GPU используется при совместимых установленных CUDA/cuDNN; полный CUDA runtime
не входит в архив. При ошибке CUDA выполняется повторная попытка на CPU.

## Run — готовое приложение

Скачать готовую Windows-сборку: [GitHub Releases](https://github.com/bxm0q/VoxTypeX/releases).

1. Распакуйте `VoxTypeX-0.1.0-win-x64.zip` в обычную папку.
2. Запустите `VoxTypeX\VoxTypeX.exe` двойным щелчком.
3. Найдите значок «V» в трее, при необходимости среди скрытых значков.

Переносите **всю папку VoxTypeX**, включая `_internal`. Один `.exe` отдельно не работает.
Для ярлыка используйте «Отправить → Рабочий стол». Запускайте одну копию программы.

## Использование

1. Правый щелчок по значку → «Настройки…»; выберите микрофон, язык и модель.
2. «Изменить клавишу» → нажмите и отпустите свободную PTT. Назначение сохраняется сразу;
   Esc отменяет его. Другие поля сохраняются кнопкой «Сохранить».
3. Закройте настройки, откройте Блокнот и поставьте курсор в текстовое поле.
4. Зажмите PTT, скажите «Привет, это проверка голосового ввода», отпустите PTT.
5. Дождитесь вставки. Во время обработки не печатайте и не переключайте поле.

Первая диктовка скачивает модель с Hugging Face. На экране показываются запуск,
скачивание, загрузка в память и распознавание. Small занимает примерно 500 МБ;
Tiny/Base меньше. Весовые файлы не входят в ZIP. Для офлайн-переноса заранее
скопируйте **весь** готовый кэш модели с сохранением структуры.

Данные пользователя:

- Настройки: `%LOCALAPPDATA%\VoxTypeX\settings.json`.
- Модели: `%LOCALAPPDATA%\VoxTypeX\models`.
- Журнал: `%LOCALAPPDATA%\VoxTypeX\logs\voxtypex.log` — 1 МБ и три архивных файла.

Полные распознанные фразы в обычный журнал не записываются. Аудио по умолчанию
остаётся в памяти. Понятная ошибка показывается в интерфейсе, подробности — в журнале.
Повреждённые или будущие версии настроек не перезаписываются автоматически.

## Development

Проверенная сборочная среда — Python **3.14 x64**. Исходники требуют Python 3.12+,
но другой интерпретатор нужно проверять отдельно с нативными зависимостями.
В PowerShell из корня проекта:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check src tests packaging
```

Запуск из исходников:

```powershell
.\.venv\Scripts\python.exe -m voxtypex
```

Отдельный тестовый профиль задаётся `VOXTYPEX_DATA_DIR`, отдельный кэш моделей —
`VOXTYPEX_MODEL_DIR`. Переменные действуют и в готовой сборке.

## Build

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

Если Python Launcher отсутствует:

```powershell
.\scripts\build.ps1 -PythonPath "C:\Program Files\Python314\python.exe"
```

Скрипт создаёт `.venv-build`, устанавливает закреплённые версии из
`requirements-build.lock`, проверяет зависимости, Ruff и unit tests,
затем собирает PyInstaller **onedir / windowed**. Результат:

- `dist\VoxTypeX\VoxTypeX.exe` и `_internal` с Python, Qt, PortAudio и библиотеками STT.
- `dist\VoxTypeX-0.1.0-win-x64.zip` и контрольная сумма SHA256.
- `dist\VoxTypeX-0.1.0-source.zip` — чистые исходники для разработки и публикации.

`packaging\launcher.py` вызывает `freeze_support()` до Qt: дочерний процесс Whisper
использует тот же `.exe`, не создавая второе приложение. Спецификация явно собирает
DLL CTranslate2 и ONNX-ресурсы Silero VAD; штатные hooks собирают PySide6,
NumPy, PyAV, ONNX Runtime и PortAudio. Модели, аудио, IDE, `.local` и окружения
не поставляются. Версии закреплены для повторяемого процесса;
ZIP не обещает побитовой идентичности.

Проверка `.exe` с собственной тестовой фразой в WAV mono PCM16 / 16 кГц:

```powershell
.\scripts\smoke.ps1 -SpeechWav "C:\test\speech.wav"
```

Проверяются настоящий трей, настройки, callbacks микрофона, frozen-процесс Whisper
с VAD и штатный выход. Тест использует отдельный профиль в `.local`;
диагностический `result.json` содержит текст тестовой фразы.
Затем выполните [сценарий с Блокнотом](docs/MANUAL_SMOKE_TEST.md).
Автоматический smoke test не заменяет реальную диктовку.

Перед первой публикацией прошли 202 unit tests, smoke test собранного EXE,
скачивание модели в пустой кэш и три живые диктовки в Блокнот.
Проверка выполнена на машине разработчика; это не проверка на чистой Windows.

## Известные ограничения

- Скорость и точность зависят от CPU, модели, шума и дикции; возможны ошибки слов и пунктуации.
- Нет гарантии вставки в любую программу: защищённые поля, UAC, приложения с правами
  администратора и нестандартные редакторы могут запрещать ввод.
- При смене поля или ручном вводе во время обработки результат не вставляется.
  Истории и отдельной кнопки копирования результата пока нет.
- PTT не блокирует обычные действия клавиш; общие конфликты с другими программами
  не определяются автоматически. Выбирайте свободную кнопку.
- Нажатие во время обработки игнорируется; после Ready отпустите и нажмите PTT снова.
  Записи короче 200 мс отбрасываются, максимум — 120 секунд.
- Нет автозапуска, установщика, автообновления и блокировки второй копии.
  Сборка не подписана сертификатом; проверка на чистой Windows выполняется отдельно.

## Структура проекта

- `src/voxtypex/` — PTT, запись, состояния, настройки, STT и вставка; `ui/` — Qt/tray.
- `tests/` — unit tests.
- `packaging/`, `scripts/`, `requirements-build.lock` — сборка и smoke test.
- `docs/` — настройки и сценарий ручной проверки.
