# VoxTypeX

Голосовой ввод для Windows. Зажмите клавишу, произнесите текст и отпустите — программа вставит его в активное текстовое поле.

Распознавание работает локально через Whisper. Аудио не отправляется на сервер.

**[Скачать для Windows](https://github.com/bxm0q/VoxTypeX/releases/latest)** · [Настройки](docs/SETTINGS.md) · [Разработка и сборка](https://github.com/bxm0q/VoxTypeX/blob/main/docs/DEVELOPMENT.md)

## Установка

На странице релиза выберите файл с окончанием `-setup-x64.exe` и запустите установщик. Ярлык на рабочем столе и автозапуск можно включить при установке.

Для запуска без установки скачайте архив с окончанием `-win-x64.zip`, распакуйте всю папку и откройте `VoxTypeX.exe`. Папка `_internal` должна оставаться рядом.

Нужны Windows 10/11 x64 и микрофон. Ориентир — 8 ГБ оперативной памяти и 3 ГБ свободного места. Python и видеокарта NVIDIA не требуются.

## Как пользоваться

1. Откройте **Настройки…** через значок V в трее рядом с часами.
2. Выберите микрофон, язык и модель. Для начала подойдёт **Base**.
3. Откройте текстовое поле, зажмите **правый Alt**, скажите фразу и отпустите клавишу.
4. Дождитесь вставки текста. Во время обработки не печатайте и не переключайте поле.

Клавишу диктовки можно изменить в настройках. **Esc** отменяет текущую операцию.

Доступны русский, украинский, английский и автоматическое определение языка. Модели: **Tiny**, **Base**, **Small** — от более быстрой к более точной.

При первом использовании выбранная модель скачивается из интернета. После загрузки можно диктовать офлайн.

## Стоит знать

- Скорость и точность зависят от компьютера, модели и качества записи.
- Защищённые поля и некоторые приложения могут не поддерживать вставку.
- Клавиша диктовки сохраняет своё обычное действие — выбирайте свободную.
- Пока нет истории распознавания и автоматического обновления. Сборка без цифровой подписи.

Настройки, модели и логи хранятся в `%LOCALAPPDATA%\VoxTypeX`. Если программа сообщает о недостающих DLL, установите [Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).

Подробности — в [настройках](docs/SETTINGS.md). Об ошибке можно сообщить в [Issues](https://github.com/bxm0q/VoxTypeX/issues).
