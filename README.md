VoxTypeX работает в трее и превращает речь в текст: зажмите **правый Alt**, скажите фразу и отпустите клавишу. После распознавания текст появится в активном поле.

Распознавание выполняется на компьютере через **faster-whisper**. Аудио не отправляется на сервер. Интернет нужен для первого скачивания выбранной модели; дальше можно работать офлайн.

## Что умеет

- Диктовка по удержанию клавиши, отмена через **Esc**.
- Выбор микрофона, языка и модели распознавания.
- Русский, украинский, английский и автоматическое определение языка.
- Индикатор записи и обработки без переключения фокуса.
- Сохранение настроек и включение автозапуска через установщик.

## Установка

1. Откройте [последний релиз](https://github.com/bxm0q/VoxTypeX/releases/latest).
2. Скачайте файл с окончанием **`-setup-x64.exe`** и запустите его.
3. Выберите папку установки. Ярлык на рабочем столе и автозапуск включаются по желанию.
4. Запустите VoxTypeX из меню «Пуск». Значок **V** появится в трее рядом с часами.

Для запуска без установки скачайте **`-win-x64.zip`**, распакуйте всю папку и откройте `VoxTypeX.exe`. Папка `_internal` должна оставаться рядом.

Нужны **Windows 10/11 x64** и микрофон с разрешённым доступом для настольных приложений. Ориентир — **8 ГБ оперативной памяти и 3 ГБ свободного места**. Python и видеокарта NVIDIA для готовой сборки не требуются.

## Первая диктовка

1. Правый щелчок по значку **V** → **Настройки…**
2. Выберите микрофон и язык, сохраните настройки.
3. Откройте Блокнот или другое текстовое поле и поставьте в него курсор.
4. Зажмите **правый Alt**, произнесите фразу и отпустите клавишу.
5. Дождитесь вставки текста. Во время обработки не печатайте и не переключайте поле.

При первом использовании модель скачивается автоматически. Это занимает время; следующие диктовки используют сохранённую модель.

| Модель | Когда выбрать |
| :--- | :--- |
| **Tiny** | Если важнее скорость или компьютер слабый |
| **Base** | Для начала: средний размер и скорость |
| **Small** | Если готовы подождать ради более точного распознавания; выбрана по умолчанию |

Клавишу можно изменить в настройках. Поддерживаются правый Alt, правый Ctrl, F6–F9, F11–F24 и боковые кнопки мыши 4/5. **Esc** отменяет запись или обработку.

## Ограничения

- Скорость и точность зависят от компьютера, модели, микрофона и фонового шума.
- В защищённые поля и некоторые редакторы текст может не вставляться. При смене поля или ручном вводе во время обработки вставка отменяется.
- Клавиша диктовки сохраняет своё обычное действие в других программах — выбирайте свободную.
- Нет истории распознавания и автообновления. Запускайте одну копию приложения. Сборка без цифровой подписи.

Настройки, модели и технический журнал хранятся в `%LOCALAPPDATA%\VoxTypeX`. Полные распознанные фразы в обычный журнал не записываются.

Если при запуске не хватает DLL, установите [Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe). Другие подробности — в [настройках](docs/SETTINGS.md).

## Для разработки

**Python · PySide6 · faster-whisper / CTranslate2 · sounddevice · pynput**

Интерфейс и трей сделаны на Qt, распознавание работает в отдельном процессе. Готовая Windows-сборка собирается через PyInstaller, установщик — через Inno Setup.
