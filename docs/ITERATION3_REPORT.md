Звуковой тракт версии 0.1.3. ASR и защита цели вставки сохранены.
Проверки ниже выполнены до добавления предпросмотра; результаты итоговой
сборки приведены в [ITERATION4_REPORT.md](ITERATION4_REPORT.md).

## Реализовано

Настоящий WebRTC NoiseSuppressor off/moderate/strong, без AGC, без моделей и сети.
Один экземпляр на запись, сохранение длины PCM и компенсация нативных 6 мс. VAD
работает по исходному сигналу, отдельно от подавления; очень тихая подтверждённая
речь сохраняется целиком. Начало имеет pre-roll 300 мс, конец — hangover 500 мс;
внутренние паузы остаются. Автостоп по умолчанию выключен.

Callback выполняет только ограниченную передачу PCM и счётчики. Очередь 64 блока,
длина записи не больше 120 секунд; overflow/underflow не маскируются. Закрытие ждёт
callback до завершения consumer. Все виджеты обновляются GUI-потоком.
Импорты DSP прогреваются фоновым исполнителем до регистрации PTT, без открытия
микрофона. Первый захват не ждёт холодного импорта NumPy и нативного runtime.

Нельзя незаметно перейти на другой вход: default закреплён, ошибку подключения
показываем, новый выбор требует явного действия. Перезапуск PortAudio запрещён
при живых input/output streams. Миграции v1–4 создают точную резервную копию;
неизвестные/повреждённые форматы не перезаписываются.
Тест и PTT разделяют одну привязку default, даже если тест был первым захватом.

`pip check` — **No broken requirements found**.

Whisper встретил RuntimeError CUDA, автоматически повторил распознавание на CPU
и вернул текст. Отдельные модели также проверены на CPU. Native runtime ASR
в этой итерации не пересобирался: использован существующий закреплённый CPU build.

Установочный тест выполнен в отдельном каталоге с кириллицей. Существующие
ярлыки сохранены и восстановлены с проверкой SHA256; тестовые записи реестра удалены.
Архивы не содержат моделей ASR или пользовательского аудио; в source ZIP нет
скачанных библиотек. В app ZIP сохранены нативные DLL и полные лицензии.

Исходный baseline: 300 passed.
Новые тесты не скачивают модели. Настоящий микрофон дал 6080 отсчётов за короткую
пробу, 16 кГц mono PCM16, без overflow. Первое открытие WASAPI обнаружило
`Invalid sample rate`; shared-rate conversion исправлен на том же устройстве,
regression test сначала воспроизвёл отсутствие настройки, затем прошёл.

Реальные пробы FLEURS с синтетическим шумом: умеренный режим уменьшил RMS шума
примерно на 10.5 дБ, сильный — на 16.3–16.8 дБ; в этих выходах нет clipping.
SI-SDR исходных 8 дБ стал 11.57–14.16 дБ / 9.75–13.19 дБ соответственно.
Это малый искусственный эксперимент; сильное подавление заметнее искажает голос.
Измеренный p95 обработки кадра 20 мс — не более 0.039 мс на данном CPU после прогрева.
Это время DSP, не задержка диктовки и не доказательство улучшения точности ASR.

Для проверки границ сравнивалась выдача того же native ASR на исходном и обработанном
VAD сигнале. Для каждой строки совпали все нормализованные слова, включая первое
и последнее; Whisper fallback не использовался.

| Язык | Обычная запись, слов до → после | Уровень ×0.05, слов до → после |
|---|---:|---:|
| RU | 21 → 21 | 21 → 21 |
| UK | 14 → 14 | 14 → 14 |
| EN | 21 → 21 | 20 → 20 |

Дополнительно совпали все 8 коротких фрагментов, на которых исходный ASR возвращал
непустой текст. Спектральная проверка короткого кандидата ограничена его длиной;
повторяется только анализ, аудио в ASR не повторяется. Стационарные tone/fan/white
сигналы длительностью 0.4, 0.6, 1.1 и 6 секунд отвергнуты.

Это проверка сохранения слов относительно исходной записи, а не WER по эталонной
расшифровке. Три прочитанные фразы не доказывают качество на любой живой речи.

Исправлены: потеря последнего callback при stop;
скрытый сброс default pin при несвязанных настройках; невозможность повторить
инициализацию после ошибки refresh; PTT между сохранением и явной перепривязкой.
Также исправлен выбор разных default-устройств для теста и PTT после смены входа
в Windows. Отдельный hook устраняет ошибку PyInstaller, который искал метаданные
`webrtcvad` вместо установленного `webrtcvad-wheels`.
Регрессионные тесты в каждом случае сначала падали, затем прошли.

Одиночный громкий щелчок больше не определяет усиление классификатора для всей
тихой записи. В четырёх вариантах (щелчок в начале/середине, автостоп выкл/2 с)
сохранены все 13.58 с PCM побайтно; автостоп наступил в 12.18 с, после окончания
речи в 10.58 с. Короткая EN-фраза 0.4 с с автостопом 2 с завершилась в 2.40 с;
дополнительная проверка кандидата выполнялась один раз.

## Ручной сценарий Windows

1. Откройте настройки: запись не начинается. Выберите микрофон; нажмите тест,
   произнесите одну фразу. Сравните оригинал/умеренное/сильное, пик и clipping.
2. Выключите VAD и шумоподавление: проверьте обычную диктовку. Включите VAD:
   сразу после PTT скажите «да», затем длинную фразу с тихим окончанием.
   Повторите тихую фразу после одиночного щелчка рядом с микрофоном.
3. Держите PTT: несколько секунд молчания, речь, длинная пауза, ещё речь.
   Первое слово и окончание должны сохраниться; тишина и вентилятор не дают вставки.
4. Включите автостоп 3 с: пауза 0.5–1 с не завершает фразу, длинная — завершает.
   Затем отпустите PTT и начните новую запись. Esc отменяет запись и обработку.
5. Отключите выбранный USB-микрофон во время записи, подключите обратно, обновите
   список. Запись с другого входа не начинается без выбора/подтверждения. Проверьте
   Windows default после изменения устройства, клавиши и выключения/включения приложения.
   Тест и PTT должны использовать один закреплённый вход, даже после смены default в Windows.
6. Смените окно/поле до готовности текста: он не вставляется в другую цель.
   Закройте приложение во время теста/диктовки и повторите после запуска.

## Ограничения

- Windows 10, физическое отключение USB и защищённые сторонние поля отдельно не проверены.
- Небольшие публичные прочитанные фразы и синтетический шум не заменяют проверку
  разговорной речи с пользовательского микрофона. Качество меняется от уровня и шума.
- Очень тихая речь сохраняется с паузами; автостоп консервативен при сомнительном фоне.
- Шумоподавление не восстанавливает перегруженный микрофон; clipping требует уменьшить усиление.
- Измерения относятся к данному CPU. Новое GPU-ускорение не добавлялось.
- В этой среде CUDA Whisper не прошла; рабочий CPU fallback проверен. Успех на GPU не заявляется.
- Python 3.12/3.14 wheels доступны, но запуски выполнены на 3.13; чистая Windows не проверена.
- Аудио теста существует только в памяти. Существующий явно включаемый debug_wav остаётся
  прежней функцией; в проверках он выключен. В логи PCM/расшифровки не записывались.
