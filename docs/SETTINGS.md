# Настройки VoxTypeX

Откройте значок V возле часов → **Настройки…**.

- **Изменить клавишу** → нажмите и отпустите Right Alt, Right Ctrl, F6–F9, F11–F24 или боковую кнопку мыши 4/5. Назначение сохраняется сразу. Esc отменяет назначение.
- **Микрофон** → выберите устройство или оставьте системное по умолчанию. «Обновить» перечитывает доступные устройства.
- **Звук** → шумоподавление, VAD, запас до/после речи и автостоп. Кнопка теста записывает до 3 секунд в память; оригинал и обработка прослушиваются отдельно. [Подробности](AUDIO_PIPELINE.md).
- **Язык** → Auto, Russian, Ukrainian или English.
- **Модель** → Tiny (быстрее), Base (баланс), Small (точнее, выбрана по умолчанию). Новая модель скачивается при первом использовании.
- **Индикация** → включите или отключите изменение цвета значка при записи и обработке.
- Нажмите **Сохранить**. Закрытие без сохранения отменяет изменения полей, кроме уже назначенной PTT.

Пока настройки открыты, PTT не записывает звук. Текущая операция отменяется;
дочерний процесс распознавания завершается, результат не вставляется.
Настройки применяются без перезапуска, между операциями. Выбор другого языка
не требует повторной загрузки модели.

В трее **Отключить** запрещает PTT и отменяет текущую операцию. **Включить**
возвращает работу. Состояние сохраняется при перезапуске; отпустите удерживаемую
клавишу перед следующей записью. **Выход** полностью закрывает приложение.

Настройки: `%LOCALAPPDATA%\VoxTypeX\settings.json`.
Логи: `%LOCALAPPDATA%\VoxTypeX\logs\voxtypex.log`.
Модель: `%LOCALAPPDATA%\VoxTypeX\models`.
В тестовом профиле `VOXTYPEX_DATA_DIR` настройки и логи находятся в указанной папке.

Текущая схема настроек — v6. При обновлении v1/v2/v3/v4/v5 создаётся
`settings.json.vN.bak` соответствующей версии с исходными байтами.
Если такая копия уже существует и отличается, новая получает числовой суффикс.
Повреждённые настройки и неизвестная будущая версия не перезаписываются.

Два технических поля доступны в JSON при закрытом приложении:
`asr_backend` — `"faster-whisper"` или `"transcribe-cpp"`,
`transcription_timeout_seconds` — общий timeout обработки после записи,
от 1 до 3600 секунд (по умолчанию 900). Поля `ru_quality`, `uk_quality`,
`en_quality` — `"compact"` / `"accurate"`. Установка и ограничения отдельных
моделей описаны в [LOCAL_MODELS.md](LOCAL_MODELS.md).
Перевод и AI в этой версии не включены.

«Текст во время записи» включает batch-предпросмотр в индикаторе без вставки
в другие программы. Интервал — 1–10 с (по умолчанию 1.5), окно — 4–20 с
(по умолчанию 8). Нужны VAD и индикация. JSON-поля: `preview_mode`
(`off` / `preview`), `preview_interval_seconds`, `preview_window_seconds`.
Настоящего потокового decode и live-typing у подключённых адаптеров нет.
[Возможности моделей, измерения и ограничения](TRANSCRIPT_PREVIEW.md).

## Ограничения

- PTT не подавляет обычное действие клавиши или боковой кнопки мыши. Выбирайте
  кнопку, которая не мешает работе в целевом приложении. Нельзя надёжно определить
  все конфликты с сочетаниями других приложений.
- Буквы, Enter, Space, Escape, Windows, левые модификаторы и сочетания не назначаются.
  Повторы игнорируются; потеря фокуса и ожидание более 15 секунд отменяют назначение.
- Отключённый сохранённый микрофон не заменяется другим незаметно. Выберите доступный
  в настройках. Одинаковые неразличимые имена в одной аудиосистеме считаются неоднозначными.
- Выход — 16 кГц, mono PCM16. В WASAPI shared mode Windows преобразует частоту
  устройства. Список обновляется без перезапуска; при ошибке драйвера повторите
  «Обновить». Другое устройство используется только после явного выбора/подтверждения.
- Автозапуск настраивается установщиком и по умолчанию выключен. Чтобы изменить
  его или ярлык на рабочем столе, повторно откройте установщик и измените галочки.
- Записи короче 200 мс без подтверждённой VAD речи отбрасываются; подтверждённая
  короткая фраза сохраняется. Максимальная длительность — 120 секунд.
  Нажатия во время обработки игнорируются. После готовности отпустите и нажмите клавишу снова.
- Если поле сменилось или во время обработки был ручной ввод, текст не вставляется.
  Истории распознавания и отдельной кнопки копирования результата пока нет.
- В защищённые поля, приложения с правами администратора и некоторые редакторы
  вставка может быть недоступна. Скорость и точность зависят от модели, компьютера и качества записи.
- Автоматического обновления пока нет. Готовая сборка без цифровой подписи.
- Вторая копия приложения не блокируется автоматически. Запускайте одну копию.

## Данные и удаление

Аудио по умолчанию остаётся в памяти. Полные распознанные фразы в обычный журнал
не записываются. Журнал ограничен 1 МБ и тремя архивными файлами; подробности ошибок
можно найти в `%LOCALAPPDATA%\VoxTypeX\logs\voxtypex.log`.

Для переноса моделей на другой компьютер скопируйте весь готовый кэш из
`%LOCALAPPDATA%\VoxTypeX\models`, сохранив структуру папок.

Перед переустановкой или удалением завершите приложение через трей → **Выход**.
Удаление: **Параметры Windows → Приложения → VoxTypeX → Удалить**.
Настройки, модели и логи сохраняются в `%LOCALAPPDATA%\VoxTypeX`.

## Требования и запуск

Нужны Windows 10/11 x64 и микрофон с разрешённым доступом для настольных приложений.
Ориентир — 8 ГБ оперативной памяти и 3 ГБ свободного места. Python и видеокарта
NVIDIA для готовой сборки не требуются.

В [последнем релизе](https://github.com/bxm0q/VoxTypeX/releases/latest) доступны установщик
`-setup-x64.exe` и переносная версия `-win-x64.zip`. ZIP нужно распаковать целиком:
`VoxTypeX.exe` и папка `_internal` должны оставаться рядом.

Если при запуске не хватает DLL, установите
[Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
